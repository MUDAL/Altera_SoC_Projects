# Simulations for the different parts of the Bin2BCD Design  

## Script-based Verification: Automated Testbench Execution  

For Windows users:

Run the following batch files in Windows PowerShell to automate the verification of the desired RTL design.  

1. `cmd.exe /c 'run_bin2bcd_tb.bat'` to simulate [bin2bcd.sv](../rtl/bin2bcd.sv)   
2. `cmd.exe /c 'run_bin2bcd_mm_tb.bat'` to simulate [bin2bcd_mm.sv](../rtl/bin2bcd_mm.sv)    
3. `cmd.exe /c 'run_counter_tb.bat'` to simulate [counter.sv](../rtl/counter.sv)
