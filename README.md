# Altera System-on-Chip (SoC) Projects
Custom hardware-software co-design projects by Olaoluwa Raji for experimentation and learning. The designs are implemented on a DE1-SoC board. SystemVerilog is used for the RTL designs for the FPGA section of the SoC, while C is used for the application software running on the processor side of the SoC.

## Tools
- Terasic DE1-SoC board
- Quartus Prime 18.1
- Platform Designer  
- SoC EDS Command Shell
- Micro SD card
- Flash drive
